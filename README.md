# INFOT 2 Sky & Cloud — Combined Enhanced Website

This version uses the **INFOT 2 Sky & Cloud website as the main design/code base**. The personal information and laboratory content were taken from the second website (`code.zip`) and integrated into the INFOT 2 multi-page structure.

## Main pages
- `login.html` — local laboratory login/sign-up demo; personal name is not shown on the login screen.
- `index.html` — main INFOT 2 home page with the combined personal information.
- `skills.html` — HTML, CSS, JavaScript skills and hobbies.
- `goals.html` — learning goals based on the original laboratory information.
- `funfacts.html` — gaming, technology, web design, and sky-theme facts.
- `gallery.html` — favorite picture plus the Sky & Cloud visuals.
- `contact.html` — JavaScript-validated form and the provided contact information.

## What was combined
The content integrated from the original `code.zip` includes:
- BSIT-2B / Bachelor of Science in Information Technology
- HTML, CSS, and JavaScript
- Gaming
- Learning Technology
- Exploring Web Design
- Favorite picture and its description
- YouTube and GitHub
- Email, location, phone, and Facebook link
- INFOT 2 laboratory learning focus
- Featured YouTube video

The **Sky & Cloud visual system, multi-page navigation, login demo, animations, gallery lightbox, theme toggle, tabs, goal cards, and responsive layout** remain based on the INFOT 2 website.

## Run
1. Extract the ZIP.
2. Open `INFOT2_Sky_Cloud_Website_Combined/` in VS Code.
3. Open `login.html` with Live Server, or open it directly in Chrome.
4. Create a demo account, then sign in.

## Authentication note
The login is only a browser `localStorage` demonstration for a school project. It is not production authentication and should not be used for real passwords.

## Notes
- `images/favorite-picture.svg` was copied from the original `code.zip` website.
- External YouTube/Facebook/GitHub links require an internet connection.
- The contact form is a front-end validation demo; it does not actually send email.
